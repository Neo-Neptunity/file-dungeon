# ファイル・ダンジョン

フォルダをダンジョンにして遊ぶアクションゲームです。フォルダが部屋、サブフォルダが扉、ファイルがモンスターになります。

討伐対象は、**長く使われていないファイルだけ**です。最近使ったものは守られて、画面に出ません。

[explorer_plus](https://github.com/Neptunity-git/explorer_plus) の MOD です。`neo.file-dungeon` 0.3.0。まだ 1.0 より前です。育てている途中なので、動きや保存の形が変わることがあります。

## 遊びかた

| 操作 | 動き |
|---|---|
| W A S D | 移動 |
| 左クリック・J | 斬る。3 連で大技 |
| Shift・Space | ダッシュ |
| Q | 回転斬り |
| F | 近くの扉に入る |
| E | 回収の確認 |

- 扉は、クリックすると歩いていって入ります。
- 倒したファイルは、すぐには消えません。「回収待ち」にたまり、最後に倒してから少しすると、本体の確認が 1 回出ます。確認を通したものだけが、ごみ箱へ送られます。
- Windows・Program Files・ProgramData の中と、`dll` などのシステムの部品は、攻撃できません。
- 討伐対象にする未使用の日数は、設定で変えられます。標準は 730 日です。

## 通信（任意）

通信先は 3 つです。どれも設定で止められます。**送るのは、ファイル名・拡張子・サイズ・未使用の期間だけです。ファイルの中身は読まず、送りません。**

| 通信先 | 使いみち | 送るもの | 止めかた |
|---|---|---|---|
| `api.anthropic.com` | モンスターのセリフと冒険日誌を、Claude に作ってもらう | ファイル名・拡張子・サイズ・未使用の期間 | 「AIでセリフと日誌を作る」をオフ。API キーが無いときも、手元のセリフを使う |
| `api.dicebear.com` | モンスターの見た目の絵を取る | ファイル名から作った印（ハッシュ）だけ。名前そのものは送らない | 「モンスターの見た目」を「使わない」にする |
| `api.open-meteo.com` | 現実の天気を、ダンジョンに映す | 選んだ都市の緯度と経度 | 「現実の天気を反映する」をオフ |

Anthropic の API キーは、設定の「Anthropic の API キー」に入れます。キーは本体が預かり、MOD のコードには渡りません。

## 入れ方

1. [Releases](https://github.com/Neo-Neptunity/file-dungeon/releases) を開き、いちばん新しい版の zip（`neo.file-dungeon-版.zip`）をダウンロードします。「Source code」ではなく、自分で付けた zip のほうです。
2. explorer_plus のホームの「MOD」の欄で「＋ MOD を入れる（zip）」を押して、zip を選びます。解凍はしません。
3. 確認の画面の「このビューが使う情報」と、通信先を読んで、よければ入れます。

## 使う情報

| 使う情報 | 使いみち |
|---|---|
| `entries` | フォルダの中身を、部屋・扉・モンスターにする |
| `size` `modified` | 大きさと更新日時で、モンスターの強さと、討伐対象かどうかを決める |
| `thumbnails` | 設定でオンにしたときだけ、縮小画像をモンスターの顔に使う。アクセス日時が更新されるので、標準はオフ |
| `fileInfo` | アクセス日時と作成日時を読んで、「使ったかどうか」を見分ける。設定の「アクセス日時も見る」がオンのときだけ |
| `recent` | 最近使ったファイルを、守る |

## 設定

討伐対象にする未使用の日数・アクセス日時も見る・モンスターの最大数・モンスターが反撃する・効果音・サムネイルを顔に使う・隠しファイルも出す・AI の使用とモデル（Haiku 5.5 / Sonnet 5.5）・API キー・モンスターの見た目・天気とその場所（札幌・仙台・東京・名古屋・大阪・福岡・那覇）。
